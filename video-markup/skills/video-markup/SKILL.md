# Разметка видео: таймкоды по содержанию

Скилл покрывает весь путь «видео → таймкоды» и умеет стартовать с любого шага.

## Определение входа

Аргумент (или указанный пользователем файл) может быть:

- **`.vtt`** → транскрибация уже есть, сразу к разделу «Построение таймкодов».
- **видео** (`.mp4`, `.mov`, `.mkv`, `.webm`, `.m4v`) → сначала «Транскрибация», затем таймкоды.
- **аргумента нет** → искать в текущей директории:

  ```bash
  ls *.vtt 2>/dev/null; ls *.mp4 *.mov *.mkv *.webm *.m4v 2>/dev/null
  ```

  - Найден ровно один подходящий файл → взять его (при наличии и `.vtt`, и видео — предпочесть `.vtt`, но сказать об этом пользователю).
  - Найдено несколько → перечислить и спросить, какой использовать.
  - Не найдено ничего → вывести:

    > Не найдено ни видео, ни транскрибации. Укажи путь, например: `/video-markup:timecodes path/to/video.mp4`

### Что делать, если пользователь просит только часть пайплайна

- «только транскрибируй», «сделай только .vtt» → выполнить **только** транскрибацию и вернуть путь к `.vtt`.
- «только оглавление», `.vtt` уже есть → выполнить **только** построение таймкодов.
- Обычная формулировка («обработай видео», «разметь видео») → выполнить оба шага подряд, без промежуточных подтверждений.

## Транскрибация

Запустить субагента `video-transcribe` через Agent tool (`subagent_type: video-transcribe`), передав путь к видео. Агент конвертирует видео в WAV 16 kHz mono через `ffmpeg`, прогоняет через `whisper-cli` и возвращает путь к `.vtt` рядом с видео.

Агент вернул ошибку → показать её пользователю и остановиться, таймкоды не выдумывать.

## Построение таймкодов

1. Прочитать весь файл транскрибации (`.vtt`) целиком.
2. Непонятные или искажённые распознаванием термины интерпретировать в контексте предметной области — определить её по содержанию (программирование, СУБД, DevOps и т.д.).
3. Разбить текст на смысловые группы по темам обсуждения.
4. Количество таймкодов — пропорционально длительности видео (последний таймкод `.vtt` = длительность):
   - до 30 минут — 5–10 таймкодов;
   - 30–60 минут — 10–15;
   - 60–120 минут — 15–20;
   - более 120 минут — 20–30.
5. Вывести результат в формате:

   ```
   00:00 - Название темы 1
   03:15 - Название темы 2
   ```

6. Не добавлять вводный текст и пояснения — только список таймкодов.

### Смещение начала

Если пользователь говорит, что обрезал начало видео на N секунд/минут — вычесть это время из всех таймкодов. Уходящие в минус значения заменять на `00:00`.

## Настройки

Пути к whisper и язык распознавания задаются в `.claude/video-markup.local.md` текущего проекта либо переменными окружения — см. `references/configuration.md`.
