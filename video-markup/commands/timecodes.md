Построй таймкоды для: $ARGUMENTS

Если аргумент пустой — найди подходящий файл в текущей директории по правилам скилла.

Действуй по скиллу `video-markup` этого плагина:

1. Вход `.vtt` → сразу строй таймкоды.
2. Вход видео (`.mp4`/`.mov`/`.mkv`/`.webm`/`.m4v`) → сначала запусти субагента `video-transcribe` (Agent tool, `subagent_type: video-transcribe`), получи путь к `.vtt`, затем строй таймкоды.

Выведи только список таймкодов в формате `MM:SS - Название темы`, без вводного текста.
