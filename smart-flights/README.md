# smart-flights

Плагин для Claude Code: ищет авиабилеты в двух источниках и ранжирует их по тому,
что важно именно в этой поездке, а не по одной цене.

Отличие от обычного поиска — в трёх вещах:

- **Полная цена, а не тариф.** К тарифу добавляется оценка сбора за багаж по правилам
  перевозчика. Ryanair с чемоданом регулярно оказывается дороже Vueling без доплат.
- **Оптимальность вместо дешевизны.** Варианты ранжируются по пяти осям: цена, время
  в пути, пересадки, удобство времени, надёжность стыковки. Веса выводятся из задачи
  поездки, а не задаются вручную.
- **Проверка стыковок.** Учитываются минимальное время пересадки, смена аэропорта,
  ночные стыковки и маршруты, собранные из разных броней.

## Установка

```bash
/plugin marketplace add AndrKonst/aka_claude
/plugin install smart-flights
```

Затем один раз создайте окружение Python:

```bash
bash ~/.claude/plugins/marketplaces/aka_claude/smart-flights/install.sh
```

Нужен Python 3.11 или новее. После установки перезапустите Claude Code —
MCP-сервер подключится автоматически.

## Токен Aviasales (необязательно)

Без токена плагин работает на одном источнике — Google Flights. Токен добавляет
второй источник и заметно улучшает покрытие российских и среднеазиатских перевозчиков.

1. Зарегистрируйтесь в [Travelpayouts](https://www.travelpayouts.com) — это партнёрская
   программа Aviasales, API выдаётся там же. Регистрация бесплатная.
2. Откройте раздел инструментов и скопируйте API-токен.
3. Добавьте его в окружение:

```bash
export AVIASALES_API_TOKEN=ваш_токен
```

Либо впишите в файл настроек (см. ниже) в поле `aviasales_token`.

## Настройка профиля

Скопируйте `config/smart-flights.example.json` в один из путей:

- `.claude/smart-flights.json` — настройки проекта;
- `~/.claude/smart-flights.json` — общие настройки.

```json
{
  "currency": "EUR",
  "home_airports": ["SVQ"],
  "baggage": {"checked_bags": 0, "carry_on": true},
  "nearby_radius_km": 150
}
```

`home_airports` — аэропорт по умолчанию, когда пункт вылета не назван.
`baggage` — что вы обычно берёте с собой; от этого зависит расчёт полной цены.

## Использование

```
/flights Севилья Берлин 4 октября, надо быть до обеда
/flights Мадрид Лондон 12-15 ноября, подешевле, багаж с собой
/flights-report
```

Или просто словами: «найди билеты из Севильи в Берлин на 4 октября».

Если не сказать, что важнее, плагин спросит: дешевле, быстрее, баланс или комфорт.
Если задача описана словами — веса построятся из неё сами, а жёсткие требования
(«надо быть до 9 утра», «бюджет 300») станут ограничениями.

## Состав

**Команды**

| Команда | Что делает |
|---|---|
| `/flights` | Поиск и ранжирование |
| `/flights-report` | HTML-страница с разбором вариантов |

**Скиллы**

| Скилл | Назначение |
|---|---|
| `flight-criteria` | Превращает задачу поездки в веса и ограничения |
| `flight-search` | Поиск, сравнение, вывод таблицы |
| `flight-report` | Сборка HTML-отчёта по шаблону |

**Инструменты MCP**

| Инструмент | Назначение |
|---|---|
| `get_profile` | Текущие настройки поиска |
| `resolve_place` | Название города → IATA (понимает русские названия) |
| `nearby_airports` | Аэропорты в радиусе N км |
| `search_flights` | Поиск по маршруту во всех источниках |
| `search_flexible_dates` | Цены по дням в окне ±N |
| `rank_offers` | Ранжирование по весам и ограничениям |
| `build_booking_links` | Ссылки на покупку |

## Что важно знать про данные

Плагин не скрывает ограничения источников — они попадают в выдачу как пометки.

- **Google Flights** отдаёт актуальные цены, но доступ к ним держится на разборе
  публичной страницы. Если Google поменяет формат, источник временно перестанет
  отвечать — плагин скажет об этом прямо, а не выдаст «рейсов нет».
- **Aviasales** отдаёт цены из кэша поисков других пользователей за последние 48 часов.
  Это ориентир, а не гарантированная цена.
- **Стоимость багажа** — оценка из `data/baggage_fees.json`, а не тариф перевозчика.
  Файл можно править под себя, он читается при каждом запуске.
- **Ссылки на покупку** ведут в поиск с подставленным маршрутом, а не в конкретную
  бронь: ни один из бесплатных источников не выдаёт ссылку на готовую бронь.
  Поле `precision` показывает точность: `search` — поиск с датами, `home` — главная
  страница перевозчика.


аэропортов, ссылки и профиль.
