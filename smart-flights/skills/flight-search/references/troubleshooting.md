# Сбои и что они значат

## Источник вернул ошибку

Диагностика в поле `sources` ответа `search_flights`.

| Сообщение | Причина | Что сказать пользователю |
|---|---|---|
| `токен не настроен — источник пропущен` | Нет `AVIASALES_API_TOKEN` | Ищем только по Google Flights; токен даст покрытие российских перевозчиков — как получить, написано в README |
| `Aviasales отклонил токен` | Токен неверен или истёк | Проверить токен в кабинете Travelpayouts |
| `Aviasales: превышен лимит запросов` | Упёрлись в rate limit | Подождать; сузить окно гибких дат |
| `Google Flights изменил разметку страницы` | Google поменял формат ответа | Источник временно нерабочий, нужен апдейт плагина. Не выдавать это за «рейсов нет» |
| `Google Flights недоступен` | Сеть, DNS или блокировка | Проверить соединение |

## Инструменты smart-flights недоступны вовсе

Если в сессии нет ни одного инструмента `smart-flights`, значит MCP-сервер не
запустился. Частые причины:

- **Окружение Python не создано в этом проекте.** Оно живёт в
  `<проект>/.claude/smart-flights/.venv`, отдельно для каждого проекта.
  Лечится запуском `install.sh` плагина из корня проекта.
- **Плагин включён в другом проекте.** Область действия выбирается при установке:
  `local` и `project` действуют только в своём проекте.

Точная причина видна во вкладке Errors у `/plugin` — обёртка запуска пишет туда,
какой именно интерпретатор она искала.

## Пусто, хотя рейсы существуют

- **Слишком жёсткие ограничения.** Смотри `excluded` в ответе `rank_offers`:
  варианты нашлись, но отсеяны. Скажи, какое ограничение мешает.
- **Дата слишком далеко.** Google отдаёт примерно год вперёд, дальше пусто.
- **Маршрут без прямого сообщения** и задан `max_stops: 0`.
- **Аэропорт распознан не тот.** Проверь `resolved` в ответе: «Сан-Хосе»
  и подобные названия встречаются в разных странах.

## Выдача выглядит странно

- **Все варианты одной авиакомпании** — нормально для коротких европейских
  маршрутов, где рынок поделён.
- **Тариф ниже, а полная цена выше** — сработала оценка багажа. Ryanair с чемоданом
  регулярно дороже Vueling без доплат.
- **Цена Aviasales сильно ниже Google** — кэш мог устареть или это другой тариф.
  Такую цену подавай как ориентир, а не как факт.

## Медленный поиск

Гибкие даты — это отдельный запрос на каждый день. `flex_days: 3` даёт семь
запросов, `flex_days: 7` — пятнадцать. Если пользователь ждёт быстрого ответа,
начни с узкого окна.
