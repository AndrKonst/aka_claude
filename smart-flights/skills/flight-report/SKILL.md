# HTML-отчёт по результатам поиска

Шаблон: `assets/report-template.html`. Он самодостаточен — стили и скрипт внутри,
внешних загрузок нет, тёмная и светлая темы поддержаны.

## Как собирать

Скопируй шаблон в файл отчёта и **замени только содержимое блока**
`<script type="application/json" id="report-data">`. Разметку, стили и скрипт не трогай:
всё оформление уже завязано на структуру этого JSON.

```
cp <plugin>/skills/flight-report/assets/report-template.html <файл отчёта>
```

Дальше отредактируй JSON внутри скопированного файла.

## Структура данных

```json
{
  "title": "Севилья → Берлин",
  "route": "14 октября 2026 · 1 пассажир · эконом",
  "meta": ["Ранжирование: цена 35%, время 20%, пересадки 20%", "Источники: Google Flights"],
  "offers": [
    {
      "price": "67 €",
      "base_price": "32 €",
      "score": 92,
      "summary": "Vueling · прямой",
      "date": "2026-10-14T23:10:00",
      "duration_min": 105,
      "stops_label": "прямой",
      "legs": [
        {"departure": "2026-10-14T23:10:00", "arrival": "2026-10-15T00:55:00",
         "from": "SVQ", "to": "BCN", "flight": "VY2221", "next_day": true,
         "layover": "BCN 1ч20м"}
      ],
      "risks": ["BCN: 45 мин на пересадку при минимуме 60"],
      "notes": ["Багаж примерно +25 € (SVQ→BCN, FR)"],
      "links": [
        {"label": "Vueling", "url": "https://...", "hint": "сайт авиакомпании"},
        {"label": "Aviasales", "url": "https://...", "hint": "поиск"}
      ]
    }
  ],
  "calendar": [
    {"label": "11 окт, сб", "price": 54, "price_label": "54 €"},
    {"label": "12 окт, вс", "price": null}
  ],
  "excluded": [{"price": "120 €", "flight": "FR2403", "reason": "прилёт позже 09:00"}],
  "notes": ["Цены Aviasales — из кэша поисков за 48 часов"]
}
```

Что чему соответствует:

- `price` — полная цена строкой с валютой; `base_price` заполняй только когда
  багаж изменил сумму, иначе опусти — иначе в карточке появится бессмысленное «тариф 32 €» рядом с «32 €».
- `legs[].layover` — пересадка **после** этого сегмента, человеческой строкой.
- `legs[].next_day` — прилёт на следующие сутки, в карточке появится «+1».
- `risks` берутся из `risk_notes` ранжирования и выделяются цветом; `notes` — нейтральные примечания.
- `calendar` заполняй из `search_flexible_dates`; дни без цены оставляй с `price: null` —
  провал в графике честнее, чем пропуск дня.
- `excluded` — из `rank_offers`, с причиной отсева.
- `notes` внизу — оговорки об источниках и оценках. Не пропускай их.

## После сборки

Локальный файл — просто скажи путь. Если нужна ссылка, которой можно поделиться,
опубликуй файл как артефакт и отдай пользователю URL.

## Чего не делать

- Не вставляй в JSON данные, которых не было в выдаче инструментов.
- Не обрезай `notes` и `risks` ради красоты: оговорки — часть отчёта.
- Не переписывай шаблон под каждый отчёт. Нужна новая секция — добавь её в шаблон
  один раз, чтобы все последующие отчёты выглядели одинаково.
