# Пресеты для вопроса пользователю

Когда задача не сформулирована, предложи выбор через `AskUserQuestion`.

## Дешевле всего
```json
{"price": 0.70, "duration": 0.10, "stops": 0.10, "convenience": 0.05, "reliability": 0.05}
```
Ранний подъём, ночной прилёт и долгая стыковка приемлемы, если это экономит деньги.

## Быстрее всего
```json
{"price": 0.10, "duration": 0.40, "stops": 0.30, "convenience": 0.10, "reliability": 0.10}
```
Прямой рейс почти всегда победит стыковочный, даже заметно более дорогой.

## Баланс
```json
{"price": 0.35, "duration": 0.20, "stops": 0.20, "convenience": 0.15, "reliability": 0.10}
```
Умолчание плагина. Разумный компромисс, когда особых требований нет.

## Комфорт
```json
{"price": 0.10, "duration": 0.20, "stops": 0.25, "convenience": 0.25, "reliability": 0.20}
```
Дневные рейсы, минимум пересадок, запас времени на стыковках.

## Формулировка вопроса

Спрашивай о поездке, а не о весах — пользователь мыслит поездкой:

> Что для этой поездки важнее? (Дешевле всего / Быстрее всего / Баланс / Комфорт)

Если пользователь отвечает своими словами («главное успеть к обеду»), не бери
пресет буквально: это режим 1 — построй веса и ограничения из сказанного.
