Собери HTML-отчёт по результатам поиска билетов: $ARGUMENTS

Работай по скиллу `flight-report`.

Бери данные из последнего поиска в этом разговоре. Если поиска не было —
сначала выполни его по скиллу `flight-search`, затем строй отчёт.

Включи в отчёт график цен по дням, если гибкие даты проверялись, и отсеянные
варианты с причинами, если ограничения кого-то отсекли.
